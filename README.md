## 🚀 Быстрый старт

### Требования
* Git версии 2.20+
* Python версии 3.9+

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-логин/my-awesome-project.git
   cd my-awesome-project
   ```
2. Запустите основной скрипт:
   ```bash
   python src/main.py
   ```
